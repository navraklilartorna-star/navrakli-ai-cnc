# KODLAMATIC

KODLAMATIC — Engineering & Technologies.

## İlk ürün: CNC Üretim Asistanı

Türkçe parça tarifi ve teknik resim girişiyle CNC üretim planlamasına yardımcı olmayı hedefleyen web uygulaması.

## Mevcut durum

Bu sürüm arayüz prototipidir. Dosya yükleme ve parça bilgisi toplama ekranı bulunur. Henüz teknik resim geometrisini otomatik analiz etmez, takım yolu oluşturmaz, gerçek G-kod üretmez ve CNC tezgâhına bağlanmaz.

Gerçek üretim kodu; geometri, takım yolu, tezgâh/ kontrol ünitesi uyumu, çarpışma ve limit kontrolleri ile uzman onayı gerektirir.

## Geliştirme

- `npm install`
- `npm run dev`
- `npm run build`

## Teknoloji

React, TypeScript, Vite.
